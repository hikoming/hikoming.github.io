Electrician Field Pro provides calculation aids and screening results. It is not a complete NEC code book and does not certify code compliance or replace the National Electrical Code, local amendments, manufacturer instructions, engineering judgment, permits, inspections, or site verification. Code-referenced data and calculation assumptions should be reviewed for the specific installation before work begins.
